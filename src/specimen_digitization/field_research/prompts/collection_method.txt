Field: Collection Method (collection_method). How the specimen was collected, as the label writes it, such as "Berlese", "light trap", "beating" or "sweeping".

No source checks it: this field settles from the readings alone.
- Take only text with collecting context: a trap, a technique or an apparatus. A locality, a person, a date, an elevation, a determination or a preparation code is not a method; a slide code such as "<Roman month>-<dd>-<yy>-<n>" never is (G45).
- Where the specimen lived or was found ("under <substrate>", "on <host>") is the habitat, not the method.
- Copy it exactly as written, in the label's language: never translate, expand or correct it ("Berl." stays "Berl.").
- Resolve when the readings agree on the text. When the readers of a label write it differently, resolve with the text of the reader the first pass preferred (input_source decided_transcript), unless another label of this specimen whose readers agree writes another reader's text: then resolve with that text. Answer several_possibilities with each reader's text only when neither applies.
- When no reading writes a collection method, answer label_lacks_value.
