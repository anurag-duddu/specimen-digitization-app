Field: Collection Code (collection_code). A code the label writes for the collection or the collecting event, copied as written.

No source or code list checks it: this field settles from the readings alone.
- Take only text the label marks as a code for the collection or the collecting event. A code needs that context in the reading.
- The catalog prefix "FMNH INS" or "FMNHINS" and its digits are the catalog number (FMNH-INS#), never a collection code, and never an EMu record number.
- A whole slide or preparation code such as VI-24-68-7 is not a collection code (G45). A date, a place, a person or an elevation is not one either: text you read from the readings that holds a date ("IV-24-48", "24.VI.1952", a year such as "1948"), an elevation or a range of them is sent back.
- Copy the code exactly, with its letters, digits and punctuation. Never complete, expand or reformat it.
- Resolve when the readings agree on the code. When readers write it differently and nothing decides, answer several_possibilities with each reader's text.
- When no reading writes such a code, answer label_lacks_value.
