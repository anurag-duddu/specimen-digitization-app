Field: Collection Code (collection_code). A code the label writes for the collection or the collecting event, copied as written.

No source or code list checks it: this field settles from the readings alone.
- Take only text the label marks as a code for the collection or the collecting event. A code needs that context in the reading.
- The catalog prefix "FMNH INS" or "FMNHINS" and its digits are the catalog number (FMNH-INS#), never a collection code, and never an EMu record number.
- A whole slide or preparation code such as "<Roman month>-<dd>-<yy>-<n>" is not a collection code (G45). A date, a place, a person or an elevation is not one either: text you read from the readings that holds a date ("<Roman month>-<dd>-<yy>", "<dd>.<Roman month>.<yyyy>", a year such as "<yyyy>"), an elevation or a range of them is sent back.
- Copy the code exactly, with its letters, digits and punctuation. Never complete, expand or reformat it.
- Resolve when the readings agree on the code. When the readers of a label write it differently and another label of this specimen, read by two or more readers who agree, writes one reader's code, resolve with that code, unless the first pass's verdict at that difference (first_pass) names the reader it preferred: then answer several_possibilities with both. Otherwise resolve with the code of the reader the first pass preferred (input_source decided_transcript). When the first pass preferred no reader and no other label writes one reader's code, answer several_possibilities with each reader's text.
- When no reading writes such a code, answer label_lacks_value.
