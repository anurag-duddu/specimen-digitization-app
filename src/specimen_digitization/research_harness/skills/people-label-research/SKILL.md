# People research procedure

This domain procedure is available for the shared Skills adapter to load. It is
not connected to the current specialist capability roster by this lane.

1. Inventory every retained label and observation once, preserving raw Qwen and
   Muse alternatives and the decided transcript. Use exact observation IDs,
   spans, region/asset identities and native quote evidence. An organiser hint
   is not a new authority. Read surrounding lines to identify incomplete lists.
2. Separate collecting, determination, preparation and locality roles. Use
   `people.reading_assertions` and the accepted graph. Preserve names, initials,
   list order and punctuation. Do not expand initials or use shared surnames to
   merge identities. An explicit list continuation requires a qualified
   relation; do not publish its first line alone.
3. For an accepted collector event invoke the scoped `settle_collectors` utility
   with the immutable event ID. Copy its exact resolution and full reading
   lineage. The native writer validates and publishes automatically; no user
   Save is required. The utility creates neither native evidence nor identity.
4. If role, span, native quote or reader agreement is missing, record a located
   alternative and a structured `waiting_policy` collector resolution with
   `missing_policy:unstructured_label_event_unqualified`. Existing profile
   routing turns this into Needs Human work. Do not ask a conversational question
   or claim scientific exhaustion from an unavailable capability.
5. An external recordedBy assertion needs a qualified exact specimen publisher
   join and collecting event. A determination needs its identification row.
   `identified_by_irn` needs qualified read-only EMu **eparties** identity and
   the correct specimen determination relationship. Public biographies, IPT
   schema exports, catalog numbers, ecatalogue/emultimedia IRNs and occurrence
   UUIDs cannot supply that proof. Without it, copy `missing_irn_resolution`:
   null Unknown with its existing field-scoped nonblocking exception.
6. Use shared browser capture only for admitted supporting sources or qualified
   authority routes. Use shared isolated code only for exact comparison of
   captured text/results. Both must retain source/version/query/effect lineage;
   neither can write canonical fields, clear holds or acquire new credentials.
7. Consult shared procedural memory before repeating work. Store only verified
   reusable procedures, authority-qualification gotchas and safe query strategies
   in a scoped people namespace. Do not store raw private labels, person identity
   claims or previous model answers as scientific truth. Memory does not retrain
   model weights. Recheck every scientific assertion against this request.
8. Resume from durable checkpoints and completed captures. An unknown send
   remains held. One unchanged no-progress query is enough; continue independent
   owned work, preserve exact prerequisites and respect existing budgets. A
   temporary outage does not imply Deferred. Product queues remain Cleared,
   Needs Human and Deferred.
