# Specimen Digitization

Flutter client for Specimen Digitization.

Firebase is configured for Web, iOS, and Android. Authentication, Storage, and
SQL Connect packages are installed; generated SQL Connect query and mutation
bindings will be added after the service schema and connector are defined.
